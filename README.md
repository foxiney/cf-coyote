# Codeforces × 郊狼 V3 · 1.9.0

连接 Codeforces 与郊狼 DG-LAB V3 的浏览器扩展，支持判题联动、模拟模式、自定义规则、比赛练习会话与蓝牙设备管理。

适用于桌面 Chrome / Edge，使用 Manifest V3 与 Web Bluetooth。默认开启模拟模式；连接设备后仍需单独启用输出。

## 安装 / 升级

1. 从仓库 Releases 下载 `CF-Coyote-1.9.0.zip` 并解压；也可以下载仓库源码并解压。
2. Chrome / Edge 扩展管理页打开「开发者模式」，选择「加载已解压的扩展程序」。同一目录升级时点击扩展的「重新加载」。
3. 停用旧目录的插件，关闭旧控制台，再打开新控制台；刷新已经打开的 Codeforces 页面。
4. 输入 Codeforces handle，点击「验证并保存」。不需要密码或 API Key。
5. 本版首次使用默认开启模拟模式（从 1.6 升级也默认开启），后续记住你的选择。

## 1.8 连接与输出管理

- 明确区分未连接、连接中、已连接、断开中和错误；支持主动断开、连接选择中取消及失败重试。
- 一个控制台在整个连接期间独占蓝牙连接锁。第二个控制台不能初始化或抢占设备；关闭或断开原控制台后释放锁。
- **连接不等于允许输出**：连接成功、重连或页面刷新后，输出始终未启用。实机模式下必须点击「启用输出（含自动触发）」，手动实机测试也受此开关约束。
- 输出启用状态只保存在当前页面内存中，不写入持久化设置；启用时确认掉旧事件，仅处理启用后的新事件。
- 紧急停止、切换账号/模式/规则/练习、意外断线均撤销启用。解除暂停后仍需重新启用。
- 主动断开先撤销启用并归零，再断开 GATT；归零请求超过 3 秒会强制断开。页面关闭时做尽力归零，浏览器强制结束进程时无法保证该请求完成。
- 电量显示增加最后更新时间，避免将旧读数当作刚更新的数据。

## 原有功能

### 不输出的模拟模式

- 真实判题仍通过 API 监控，日志显示预计强度与跳过原因，不生成蓝牙输出事件。控制台关闭时，后台仍可记录模拟判题。
- 「模拟测试（始终不输出）」可选择 WA、TLE 等结果；即使全局已切换到实机，这个按钮也不会输出。
- 模拟测试遵守所选规则、会话状态、暂停、通道和冷却，不修改真实连败数或实际输出计数。
- 模拟与实机使用独立冷却计时。默认冷却 60 秒，可在设置中调整。
- 实机连接后的软上限初始化和归零包仍会发送；模拟判题不会发送产生刺激的包。

### 按判题配置规则

支持 WA、TLE、RE、CE、MLE、ILE 和 Hacked：

| 动作 | 行为 |
| --- | --- |
| 触发 | 模拟模式记录预计输出；实机模式尝试输出 |
| 仅记录 | 记录结果并增加连败，不输出 |
| 忽略 | 留下忽略原因，不输出、不增加连败 |

每种判题可填写独立基础强度 0–100；留空跟随基础滑块。连败递增继续生效，总强度封顶 100。预计强度为 0 时跳过。

修改后点击「保存判题规则」。修改模拟开关会一并保存规则。修改模式、规则或会话会取消当前输出并清除旧触发事件，防止旧事件套用新规则。

### 指定比赛练习会话

- 输入比赛链接里的数字 ID 和 1–480 分钟时长，点击「开始 / 重新开始练习」。比赛 ID 校验数值格式，不查询比赛是否存在。
- 仅处理会话开始后提交到该比赛的记录，其他比赛的 AC 也不会重置本会话连败或无 AC 计时。
- 开始时重新建立提交 ID 基线，清除旧 pending 和连败；此前已在评测的提交不纳入。
- 到期或手动结束后，**自动触发保持停止**，无 AC 触发也停止。不会自动回到全局监控。
- 点击「监控全部新提交」可明确恢复全局监控，并建立新的提交基线。
- 切换用户名结束旧练习。浏览器重启会恢复未到期会话，到期会话保持停止。
- 会话结束后才返回的判题不再触发。手动实机测试也遵守会话停止状态。

### 设备电量

按DG-LAB V3 协议文档读取服务 `180A` / 特性 `1500` 的一个字节，并订阅通知。0–100 显示为百分比，20% 及以下提示电量偏低；异常值显示不可用。电量读取/通知失败不会中断主连接。

连接郊狼时需要授予这项新增服务权限。若从旧版升级后显示不可用，可重新选择设备连接。

## 其他优化

- 最近 100 条事件持久化保存，可清空。记录模拟、AC、忽略、冷却、会话结束、等待控制台、输出错误等情况。超过 15 秒的待处理事件显示过期，不补发。
- 模拟、后台和控制台共享 `core.js` 中的规则归一化、强度计算和会话判断，减少判断差异。
- 停止的练习不再轮询提交；控制台完整统计由每分钟调整为每 5 分钟刷新，实时提交监控仍是网页约 15 秒 / 后台约 1 分钟。
- 改善账号区域换行、窄窗口布局；Codeforces 页面浮层展示当前模式与比赛范围。
- 保留账号验证、历史过滤、单后台去重、跨控制台输出锁、紧急停止、API 串行限流及请求超时。

## 实机使用

关闭「模拟模式」，连接郊狼 V3，再点击「启用输出（含自动触发）」，并保持控制台打开。启用后手动触发会实际输出；Esc 或「紧急停止」会中断当前发送并暂停 1 小时。模拟模式下，手动触发转为所选判题的模拟测试。

仅支持 V3 蓝牙主机（名称前缀 `47L121`）。每次连接写入 BF：A/B 软上限均为 100，平衡参数均为 0，并发送归零包、订阅实际强度通知。这些设置会改变设备保存的软上限和平衡参数。不自动重连、不补发断线期间的旧事件。

## 已知边界

- 已在 Codex 内置浏览器以模拟 Chrome API / 蓝牙对象验证连接、启用、断开、重连和两个控制台的连接互斥。没有在 Edge 扩展环境或真实郊狼设备上验证；尚未完成实机测试。
- 统计只覆盖最近 5000 次提交；每次监控读取最近 1000 次提交，超过窗口可能漏记旧提交。
- 公开 API 不一定及时提供比赛中或私有范围内的全部记录。浏览器休眠会延迟后台检查。
- 同批多个失败只发出一次输出事件，其他失败仍按规则计入连败并记录合并原因。
- API 失败保留进度，下轮重试；该轮跳过无 AC 触发。
- 会话和规则界面新增文案暂为中文；原统计区域保留中英文切换。

## 验证与代码结构

无需安装依赖，Node.js 18+：

```text
node --test tests/regression.cjs tests/connection.cjs
node --check core.js
node --check features.js
node --check background.js
node --check control.js
node --check content.js
```

30 项测试覆盖连接独占、断开归零、取消选择、意外断线、重连不恢复输出、连接但未启用不输出，以及模拟零输出、判题规则、独立冷却、比赛和时间筛选、会话基线及到期、旧规则事件拒绝、日志去重/上限、电量读取/通知/异常降级、运行中切换模式和会话到期等场景。

- `appearance.js` / `theme.css`：操作引导、动效与界面样式。
- `connection.js`：连接生命周期、设备独占与输出启用。
- `core.js`：共享纯逻辑。
- `background.js`：API 队列、判题、会话、模拟决策与事件日志。
- `features.js`：模式/规则/会话界面、日志显示。
- `control.js`：统计、蓝牙、真实输出和中断。
- `content.js`：页面状态浮层与刷新请求。
- `tests/regression.cjs`：无硬件回归测试。

协议参考 `DG-LAB-OPENSOURCE-main/coyote/v3/README_V3.md`。API 请求间隔至少 2.1 秒，遵循 [Codeforces API 文档](https://codeforces.com/apiHelp)。

页面顶部明确标注 API/蓝牙均为模拟。这是连接界面的验证夹具，仅实现预览所需 API，不能替代完整扩展或硬件测试。
`tests/browser-mock.js` 只由预览路由注入，正式 `control.html` 不会加载它。
