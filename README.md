# Codeforces × 郊狼 V3

将 Codeforces 新提交的判题结果与郊狼 V3 蓝牙设备联动的浏览器扩展。
支持判题规则、连败递增、指定比赛练习和无 AC 计时。

**默认模拟模式，无需设备即可体验判题规则和事件日志。**

当前版本：**1.9.3**。项目采用 Manifest V3，面向支持 Web Bluetooth 的桌面 Chrome / Edge。
这是个人项目，与 Codeforces、DG-LAB 无官方隶属关系。

## 1.9.3 更新

- 顶部增加最近触发结果：判题或无 AC 到期后显示输出、记录、冷却、未启用等原因；同步失败时显示等待重试。
- 分类保存设置：修改通道、强度、连败递增撤销启用；修改冷却、无 AC 时长和开关保留启用状态。
- 区分最近实际 AC、本轮无 AC 开始时间、下次检查时间。开启计时或修改时长从现在重计；到期不会覆盖 AC 时间。
- 无 AC 遇到冷却可选跳过本轮（默认）或冷却后重新同步检查；暂停、断线、未启用时不补发旧事件。重新启用会清除延期重查。
- 从旧版升级后，原混用时间只迁移为计时起点，最近实际 AC 等待新判题记录。

## 功能

- 验证 Codeforces handle 后，仅监控新提交；无需密码或 API Key。
- WA、TLE、RE、CE、MLE、ILE、Hacked 可分别配置触发、仅记录或忽略，以及基础强度。
- 支持连败递增、A/B 通道开关和独立的模拟 / 实机冷却。
- 指定比赛练习支持 1–480 分钟；无 AC 计时支持 1–240 分钟。
- 顶部常驻状态栏显示未启用、等待触发、冷却剩余时间及正在发送，并列出阻断原因。
- 支持设备电量、最近 100 条事件日志、提交统计、Rating 趋势与比赛倒计时。

## 安装

1. 下载仓库源码并解压。
2. 打开 Chrome / Edge 的扩展管理页，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的目录。
4. 点击扩展图标打开控制台，输入 handle，点击「验证并保存」。
5. 保持模拟模式，选择判题并点击「模拟测试（始终不输出）」，查看事件日志。

升级时关闭旧控制台，在扩展管理页重新加载扩展，再打开控制台并刷新已打开的 Codeforces 页面。

## 实机连接与输出

仅支持名称前缀为 47L121 的郊狼 V3 主机。

1. 完成账号和规则配置，关闭模拟模式。
2. 连接设备，再单独点击「启用输出（含自动触发）」。
3. 查看顶部状态栏，保持控制台打开。

连接成功不代表输出已启用。重连、修改通道/强度/连败递增或规则、切换账号或练习、紧急停止后均需重新启用。修改无 AC 时长、开关、冷却和冷却处理方式保留启用状态。
Esc 或「紧急停止」会取消后续发送并暂停 1 小时。不要连接他人的设备或对未同意的使用者触发输出。

每次连接会将 A/B 软上限设为 100、平衡参数设为 0，并发送归零包；这些操作会改变设备保存的参数。
正在发送表示软件发送指令，不等于设备确认输出。已交给浏览器的写入不能撤回；输出 / 归零写入超时后通过断开 GATT 处理。

## 无 AC 计时与练习范围

- 开启无 AC 计时后，从开启时刻重新计时；新 AC 重置计时。
- 控制台倒计时到期会请求检查，也每 15 秒请求监控；后台定时检查约每分钟一次。
- 检查先同步判题，最近同步失败时不触发无 AC 输出。网络、页面限速和浏览器休眠可能造成延迟。
- 冷却、模拟模式、暂停、输出启用状态、通道开关和练习范围仍然生效。
- 指定比赛练习仅处理开始后提交到该比赛的记录；结束后停止自动触发，需点击「监控全部新提交」才能恢复全局监控。

## 数据与权限

- handle、规则、统计和事件日志使用 chrome.storage.local 保存。
- 插件向 Codeforces 公开 API 请求账号、提交与比赛数据，不要求密码或 API Key。
- 蓝牙连接由用户在浏览器选择器中授权；启用状态只保存在当前控制台内存中。
- 扩展使用 tabs、storage、alarms 权限以及 Codeforces 主机访问权限。

## 验证与已知限制

**50 项模拟回归测试通过。作者已在 Edge 浏览器中进行郊狼 V3 实机测试。**

实机测试记录来自作者反馈；未记录浏览器版本和逐项测试结果，其他浏览器及设备环境尚未验证。

- 本项目的自动测试使用模拟 Chrome API / 蓝牙对象，不能替代硬件验证。
- 统计仅覆盖最近 5000 次提交；监控每次读取最近 1000 次，超出窗口可能漏记。
- Codeforces API 对比赛中或私有范围记录的可见性、更新时间可能有限。
- 同批失败合并为一次触发，其余失败仍按规则计入连败。
- 超过 15 秒的待处理事件不补发；不自动重连。
- 控制台关闭时只保留后台记录能力，不能进行蓝牙输出；强制结束浏览器时无法保证归零请求完成。
- 主要界面为中文，部分统计文案支持英文。

## 开发与测试

无需安装 npm 依赖，使用 Node.js 18 或更高版本：

```sh
node --test tests/regression.cjs tests/connection.cjs
node --check core.js
node --check background.js
node --check control.js
node --check connection.js
node --check features.js
node --check content.js
node --check appearance.js
```

GitHub Actions 工作流会执行语法检查和回归测试。

本地界面预览（需要 Python 3）：

```sh
python tests/preview_server.py
```

浏览器访问 `http://127.0.0.1:8765/preview.html`。此预览使用模拟 API / 蓝牙；正式 control.html 不加载模拟脚本。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| manifest.json | 扩展配置 |
| control.html / theme.css / appearance.js | 控制台界面 |
| core.js | 共享规则与计算 |
| background.js | API 队列、判题、计时与日志 |
| control.js / connection.js | 统计、连接和输出控制 |
| features.js | 模式、规则、练习和日志界面 |
| content.js | Codeforces 页面状态浮层 |
| tests/ | 回归测试和本地模拟预览 |
| design-reference/ | 设计参考原文及其许可 |
